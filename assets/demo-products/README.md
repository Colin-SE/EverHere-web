# 测试商品配图

这五张图片由内置 image_gen 按 `prompts.json` 生成，用于 Everhere 测试商品展示，不代表实际销售或实物规格。此目录只包含生成的公开商品示意图，没有用户私人照片、账户或订单数据。

| 文件 | 对应商品 |
|---|---|
| medal.webp | 旅行纪念奖牌：金色 / 银色 |
| keyring.webp | 成长纪念钥匙扣：木质 / 亚克力 |
| postcards.webp | 年度生活明信片 |
| ebook.webp | 电子回忆录 |
| paperbook.webp | 纸质回忆录 |

图片使用暖白与鼠尾草绿背景，已转换为 WebP，最长边不超过 1280 像素。原生成 PNG 保存在本机 `outputs/product-images/`，此处提交网页展示副本和完整提示词。

使用管理员进入商品编辑页，选择对应图片后保存即可。商品配图另存 MySQL；此目录不会自动创建商品、账号或覆盖已有封面。未登录访客只能从商品图片接口查看已上架商品；私人相册附件不作为商城封面来源。
