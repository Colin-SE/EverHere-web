# 本机优先与共同云的当前边界

2026-10-20。Android保留Room8/SQLCipher、私有原图、DataStore；Web使用独立Flask/MySQL；共同云沿用Android区域TypeScript/PostgreSQL服务，不另造云事实库。

| 用户要求的顺序 | 当前结果 |
|---|---|
| 默认本机保存 | 可用，无账号可记录，普通保存不联系云 |
| 登录不上传 | 已实现BFF，只调用共同 /v1/auth/login，不调用事实/原图传输 |
| 服务端确认有效权益 | 有拒绝保护；PG008无真实权益接口，不能取得有效授权 |
| 用户明确开启 | 缺权益/范围许可时拒绝，不设置假成功标志 |
| 选择上传/下载及范围、预览确认后执行 | 未实现，当前没有云数据执行路径 |

本机身份由签名Cookie绑定local_spaces，历史列user_id现引用该空间；users已删除。清Cookie不会清库，但目前无法通过界面找回旧空间。共同账号access存cloud_connections，不进入浏览器存储；刷新/注册/真实邮件/找回未接。10分钟access到期需重登。离线时远端退出失败，本机清凭证的独立降级仍待补齐。

CLOUD_API_URL为空不联网；配置要求同区HTTPS，回环HTTP仅供本机联调，拒绝凭证跟随重定向。CN/global区域不自动互转。换云账号不会自动将本机资料加入新账号。

Web预期 /v1/entitlements 返回同region/userId、cloudSync.active和expiresAt；该地址是后续契约，非PG008已实现能力。404/过期/归属不符都拒绝，即使返回active仍因缺按范围许可拒绝开启。

后续需要：共同服务权益来源和撤销、设备明确开启、一次性方向/范围许可、必要摘要预览、执行事务复核、幂等队列与冲突、单独原图进度、真实双端和换机验收。四种云冲突解决方案不以当前归档“保留两份”替代。没有部署公网或重新验收Android线上能力。

手动原生JSON/ZIP交换已可在本机执行；文件恢复不要求云权益，不登录、不上传手机密钥，也不把文件恢复叫联网同步。
