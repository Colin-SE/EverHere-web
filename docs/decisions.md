# 当前平台适配决策

日期：2026-10-20。以下为当前决定，已替换早期交付说明。

1. 用户指定 Flask/MySQL/原生前端，安卓工程只读。规划 v3 为完整目标；本地 Android code23 与规划 code25 有版本差异，逐项报告。
2. 一份 LifeRecord 被时间轴、日历、全部记录、地点、人物聚焦引用；编辑同ID，事件日期与系统审计分离，月/年/未知不造具体日。
3. 本机空间与共同账号独立。当前无本地密码功能，签名Cookie授权本机空间；不把云登录变成资料传输。清Cookie后的恢复界面尚缺。
4. 用户要求历史资料与旧实现直接删除，不保留备份。删除了本地账户/保险箱及旧管理界面和旧schemaVersion归档，取消演示入口；保留已执行数据库迁移链，支持已有版本明确升级。
5. 草稿与正式事实分表，版本保护、提交回执保证幂等；软删除/恢复保持ID和原图。人物删除只解绑。
6. 原图保留原始字节，不移除EXIF或重编码；批量校验后提交。敏感EXIF可能包含拍摄地点，导出时由用户决定是否携带原图。
7. 原生归档校验与Web存储投影分层，保留原始日期/时区/int64/未知字段/关系/墓碑。JSON明确缺原图；ZIP严格清单/CRC/摘要/图片校验。本机加密暂存有期限，确认执行重验目标指纹；不会自动复制历史库。
8. WARM/FOREST通过语义颜色覆盖，不改变数据；当前首页夕阳和图标源于用户原工程，最终美术及许可验收仍需收尾。地点是列表，不使用静态地球冒充3D。
9. 共同服务缺权益/按范围许可，云同步拒绝开启；缺少服务不能使用模拟成功代替。公网、付费、阶段/脉络及其他后续规划独立实施。
10. 多人集成使用模块边界、共享接口、追加迁移和独立测试库；本地运行、测试环境、生产可用分开报告。
