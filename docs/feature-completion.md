# Everhere Web 功能完成度与问题清单

核对日期：2026-10-20。依据用户提交的《Everhere 完整产品总规划 v3》，完整原文见 [产品规划](product-plan-v3.md)。本文评价本 Web 工程，Android 只作参照，未修改其代码、SQLite、照片、密钥、设置或迁移。

## 结论与基准

Web 已具备核心本机记录闭环：游客使用、记录/人物草稿、同ID编辑、五种日期精度、查询与回看、人物关联、原图浏览、软删除恢复、原生JSON/ZIP交换、两套主题。**没有完成整份产品规划，也没有完成安卓与Web联网同步。**

本机可读取 Android 工作区的 build.gradle.kts 为 **code23 / 0.0.23-b1.8**，协议基准Room8/PG008；规划第12节引用 **main b2287656、code25**。code24/25的照片拍摄日期辅助等内容没有因此被算作Web完成。未重新安装或执行Android包，本轮仅Web实现与验证。

“本机可用”指Flask/MySQL运行时可操作，业务规则经隔离测试、主要流程经真实Edge浏览器验证；不等于手机离线、公开服务器或生产验收。下表“部分实现”表示已有列出的可用子集，“未实现”表示没有可用产品闭环；模型或协议预留不算实现。

## 当前问题与限制（按影响列出）

| 编号 | 问题 | 影响 / 当前行为 | 后续处理 |
|---|---|---|---|
| P01 | 共同服务缺权益及方向/范围许可 | 云同步始终关闭，配置URL或登录也不能完成跨端；无真实公网联调 | 共同后端先实现有效授权及事务许可，再对接Web队列/冲突/原图，实际双端验证 |
| P02 | 本机空间仅由Cookie定位 | 清Cookie/换浏览器会进入新空间；数据库原数据仍在，但当前无恢复入口 | 在后续W0设计安全解锁、空间恢复和账号明确归属，不恢复已淘汰本地账户实现 |
| P03 | Web加密和离线能力不足 | MySQL普通正文/原图未做安卓同等级加密；服务关闭时不可记录 | 独立定义Web加密、解锁/密钥、临时/离线缓存及清理方案 |
| P04 | Android版本差异 | 本地code23无法证明code25日期辅助全量一致 | 获取可读的code25实现后按日期行为补齐并验收；本轮未操作安卓分支 |
| P05 | 归档和字段上限 | ZIP128MiB；标题200字、人物名120字、ID100字符等，超过Web支持范围拒绝导入，不静默截断 | 为大归档分块/流式处理，统一跨端字段上限 |
| P06 | 草稿仍有浏览器关闭边界 | 只保证服务器确认“已保存在本机”的内容；突然退出前最后输入可能未落盘；无离线队列 | 后续持久离线写入、生命周期及多标签冲突体验 |
| P07 | 图片资源生命周期未完整 | 放弃草稿/移除引用的原图不会立即物理回收，避免误删仍引用的图片，但可能占空间 | 引用计数、延迟回收、显式清理范围和失败恢复 |
| P08 | 云会话管理不完整 | access到期需重登；远端退出失败时暂不能完成本机独立清凭证 | 补刷新/撤销与离线退出状态处理，并保护换号画面 |
| P09 | 大档案性能与导航细节 | 无服务器分页、完整滚动恢复；超大日期范围交互不完整 | 定向性能样本和游标查询、返回上下文恢复 |
| P10 | 验收覆盖边界 | 自动化与Edge合成库已验，未执行Android实机反向恢复/跨端公网/生产/用户视觉验收 | 用真实用户路径单独验收，不把代码/测试数量当上线 |
