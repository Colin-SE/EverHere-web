# 中英文界面适配

完成检查日期：2026-10-23。默认简体中文，页面顶部和云登录页可选择 English；移动首页保留紧凑工具栏。语言通过 `everhere-language` Cookie 保存一年，当前站点/浏览器有效，清理 Cookie 后恢复默认。

切换重新加载页面，保留当前 URL 的视图和筛选。对话框打开、记录或人物保存、照片上传、导入待确认期间阻止切换，避免丢失操作。先完成保存或关闭对话框再切换；语言不承诺保留临时画布视口。浏览器原生日期控件、文件选择器及下载提示由操作系统/浏览器控制。

## 协作约定

- `app/locales/en.json` 是前后端共用的英文文案源，中文源文案是键。新增文案先增加条目，再运行 `.venv\Scripts\python.exe tools/build-i18n.py` 生成 `app/static/js/messages-en.js`；提交两者。
- 模板使用 `_()`，Python 使用 `translate()`；API 错误只翻译 message，不修改错误码、状态、数据和字段名。
- JavaScript 使用 `t()` 与命名插值；`h` 标签只翻译静态 HTML 片段，插值仍须沿用原有转义。禁止扫描翻译用户 DOM、日记、姓名、地点、标签或归档。
- 日期显示按界面语言格式化，保存格式与日期精度不变；预置心情显示英文，实际选项 value 仍为原协议值，自定义心情保留原文。
- 语言与 `CLOUD_REGION`、登录身份、同步权益、空间归属无关。当前没有云端语言偏好同步。
- 新功能同时维护中文和英文，新增组合句优先用命名占位符，避免拼接导致英文语序问题。代码注释继续使用中文。
