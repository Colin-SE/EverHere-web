# 人生脉络：使用说明与实现边界

更新：2026-10-21。对应产品总规划4.14。本轮实现局部探索与既有正式关系编辑，不另建事件正文库，不恢复已淘汰的线索/阶段管理页。

## 从哪里进入

首页“人生工具 → 人生脉络”、桌面侧栏、“我的 → 人生脉络”；记录详情和人物聚焦也可“在脉络中查看”。保留手机原五项底栏，不增加第六项。

首次展示“现在”，点击资料卡看摘要与来源；“展开一层关联”只请求当前节点的邻居。“还有关联”继续读下一页；“收起这一层”仅改变画面。共享节点仍有其他展开路径时保留，环按稳定ID去重。可选任意节点“以此为焦点”，并随时“回到现在”。

画布可拖动平移、滚轮/双指缩放，方向键平移、加减键缩放；提供缩放、适合画面、居中按钮。关系列表可完成选择、展开、收起、聚焦和原详情操作，不依赖精细手势。

查找既有人物/对象/记录/阶段/长期投入，可从更早经历重新开始。查找最多展示12项，继续细化关键词可找更多；类型与日期筛选可组合，保留当前焦点便于定位。月/年/范围按日期窗口匹配，不造具体发生日。

## 初始窗口与关系来源

- “现在”只是时间定位，不写入用户事实。当前阶段是明确日期范围覆盖当天的阶段。
- 正式记录满足过去30天至未来14天窗口重叠，或状态仍在进行且未完成/取消。先展示当前阶段、再进行中、再近期经历，同组按事件日期/稳定ID排序；不使用最近修改时间评判重要性。
- 每次最多6个邻居，初始最多补3个已保存的直接对象，总共最多10张卡。超过一页显示继续展开，单次画面最多80个节点。
- 实线：用户保存的记录—人物/宠物/物品等对象、记录—阶段、记录—长期投入，及原生阶段—长期投入关系。虚线：根据时间/状态计算的“现在”定位。
- 人物之间共同参与记录，只展示经由原记录的路径；不自动写入亲密、影响、转折、因果关系，不把派生路径画成直接关系。

## 怎样保存或解除关联

选中一条记录可查找并选择已有对象/阶段/长期投入；选中资料也可反向查找记录。系统展示两端名称，明确确认后按原记录版本保存。同一事实立即被原记录、人物聚焦、其他列表及归档使用。重复已有关系不重复建边。

点击某条正式关联的“解除此关联”，确认后只移除关系，原记录、对象、照片和现有草稿保留。若记录已被另一页面更新，返回409，不覆盖新内容；现有草稿在正式版本改变后也按原冲突规则保护。

阶段—长期投入的既有原生关系可浏览，本轮不新增其编辑器。新人物—人物、事件—事件、影响/转折等语义需后续正式设计；本轮不创建未定义的关系类型。

## 返回、刷新与隐私

从画布进入原记录编辑，再返回保留焦点、展开和视口，并重新读取当前正式事实；删除节点或解除关系后重新计算可见路径。返回普通人物页后再次进入，也保留本次页面会话。刷新整个浏览器时重新读取指定焦点，不保存上次视口。

画布状态仅存页面内存，不把正文、搜索结果、布局写入localStorage或云。隐藏页面/重新激活时先遮住画面，再验证当前空间，清Cookie/切换空间不展示旧节点、边或搜索结果。读取失败明确报错并提供重试，不作为“没有资料”；网络恢复后重新校验。

MySQL仍为Web事实库，Android库、设置、密钥和云同步策略未改。当前没有Web离线保存、全库加密或完整云授权，不把脉络上线当作这些能力完成。

## 技术与兼容

新增 `/api/v1/lifegraph/neighbors`、`/search`、`/snapshot`、`/relations`。读取按当前空间和普通/未删除事实限定，游标绑定空间/焦点/筛选、15分钟过期；写关系显式确认、CSRF、记录版本及数据库CAS。坐标拖动不触发写请求。

无新事实模型、无新表或迁移。正式关系复用record_nodes及原生章/线索引用；写入更新原记录审计，原日期精度/时区/int64创建时间/照片元信息保持原样。原生JSON/ZIP沿用原协议。

当前分页限制的是响应与画面；日期候选仍需按空间流式扫描，数十万条资料的索引化查询/性能尚未验收。阶段、宠物物品、长期投入的完整创建和专属详情仍按后续模块实现；已导入资料可以在脉络浏览及关联，不能将此算为这些完整模块已交付。
