|---|---|---|
| 00:00–00:25 | 团队、项目、用户需要、这次将展示的任务 | HeSicheng |
| 00:25–02:35 | 建立文字/照片记录、保存草稿和恢复；桌面与窄屏反馈；解释界面设计 | CongZheming |
| 02:35–05:05 | 选材并授权提交；管理员领取、退回、用户重提、通过后生成；解释状态、隐私及修订 | HeSicheng 为主；CongZheming 简短解释输出排版 |
| 05:05–07:45 | 浏览器到 API/MySQL 的连接；定制商品下单、沙箱支付结果及通知入账；解释快照、验签与幂等 | CuiChenshuo |

## 测试证据如何讲

每人至少选择一个自己负责或参与设计的有意义场景，明确说明参与范围。以下现有证据可供选用，最终展示前核对结果与同一代码版本对应。

| 场景 | 为什么测 | 预期与已有结果 | 入口 |
|---|---|---|---|
| 回忆录修订与授权隔离 | 防止管理员看到未授权相册、重提覆盖旧稿 | 未授权请求被拒绝，旧快照保持，旧版本审核失败 | `tests/test_workflows.py::test_two_roles_return_resubmit_generate_and_keep_immutable_selected_material` |
| 生成失败后重试 | 防止失败被显示为成品或丢失批准材料 | 保持 approved、保留快照、没有完整成品，重试后 ready | `tests/test_workflows.py::test_failed_generation_keeps_approved_snapshot_then_retries` |
| 支付通知重复及金额错误 | 外部系统会重试通知，浏览器返回也不可信 | 错误金额拒绝，重复有效通知只产生一次 paid 入账 | `tests/test_alipay_commerce.py::test_physical_checkout_callback_idempotency_and_fulfillment` |
| 两设备同时发起付款 | 防止生成两笔账或重复预占库存 | 共用同一交易并只预占一次库存 | `tests/test_alipay_commerce.py::test_two_devices_on_mysql_share_one_trade_and_one_stock_reservation` |
| 断网编辑及上传重试 | 网络失败时应保留输入，并让用户可恢复 | 文本保留；恢复网络后可上传/保存，重试不重复下单 | `tools/product-experience-browser-check.cjs` |
| 样张与完整 PDF 的边界 | 预览不能包含剩余完整页面 | 样张严格少于成品页数，未开放的完整文件 URL 不能下载 | `tests/test_report_scope.py::test_preview_is_strictly_a_subset_and_has_no_hidden_remaining_pages` |

解释结果的局限：自动化支付使用合成签名网关；本次服务器已有实际沙箱付款及通知证据；退款、账单、真机同步等仍按各自结果记录。142 项通过是整体证据，视频还需解释具体断言为什么有意义。

## 执行顺序

1. **固定演示范围与材料。** 一位普通用户、一位管理员、2–3 条合成记录和少量照片、一份可审核的稿件、一份 ready 样张、¥1 测试商品及已付款订单。若加入电子版下载，先准备对应规格并验收。不要在真实用户资料上录制。
2. **三人逐段走通。** 在同一测试站检查页面、角色切换、审核生成和付款证据。浏览器用普通窗口与无痕窗口分开用户/管理员会话；等待、跳转和外部收银台都计入时长。
3. **整理每人证据。** 各确认自己实际做的事项、一个需求与设计关系、一处实现/流程依据、一个测试的预期和结果。贡献说明不只使用 Git 作者名推断。
4. **编写英文提纲并计时。** 每人以自己的实际贡献为主，先写提纲再录口述。全片建议先排到约 9 分 30 秒；PDF 明确的英语要求是每位成员的贡献说明。
5. **录制并合并。** 网页字号可读，切换角色和模块时交代上下文，保留关键反馈。录制环境和数据库命名、验证码登录流程要与所用站点一致。
6. **交付核对。** 三人姓名及英语贡献均出现；四项评分维度有证据；一个可播放的 MP4，实际时长不超过 600 秒；两位教师已取得仓库访问；按课程平台的准确截止时间和提交位置上传。

当前待补信息：课程平台显示的准确截止时间、两位教师的仓库访问状态，以及个人提词稿中的实现与测试例子是否准确对应本人参与内容。当前稿件可以用于预演，正式录音前按实际参与内容校订。
