## 完整逻辑链应如何出现在画面中

### 1. 回忆录链

```mermaid
flowchart LR
    A[同一用户的 R1/R2] --> B[明确选材和授权]
    B --> C[M1 修订 1]
    C --> D[管理员领取并退回]
    D --> E[用户修改章节标题]
    E --> F[M1 修订 2]
    F --> G[审核通过]
    G --> H[单独启动生成]
    H --> I[该修订生成的样张]
```

应保持同一个稿件 M1，修订号从 1 变为 2；输出中的标题、修改后的章节名和选定照片与最终授权材料一致。R3 不选入。S11 通过来源记录 ID 展示界面、数据库与审核材料的连接。预览不等同于完整交付。

### 2. 独立商品付款链

```mermaid
flowchart LR
    A[同一网站账号定制商品] --> B[创建订单 O1]
    B --> C[冻结价格和选项]
    C --> D[O1 的沙箱收银台请求]
    D --> E[验签并核对通知或查询]
    E --> F[O1 标记 paid]
    F --> G[同单数据库与事件证据]
```

`ShopOrder.id` 与 `OrderTrade.order_id` 对应；`merchant_no` 与支付宝商户单号对应。不是所有 ID 都相同。纪念牌可独立下单，不要求先绑定回忆录，也不以纪念牌付款证明电子回忆录可完整下载。

如果采用历史 P1，则该历史订单可以构成独立验收案例，但不能接成新 O1 的付款结果。文件中已给备用口播；这两种剪辑方案的证据强度和可声称结果不同。
