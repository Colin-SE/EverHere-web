# v2.0 重构版

Everhere 从单一私人相册扩展为人生相册、回忆录和文创商城三个并行入口。用户与管理员通过同一份版本化提交完成选材、审核、退回修改及成品预览；普通纪念商品可以独立下单。

## 已实现

- F1：沿用相册核心能力，建立账户和空间的明确归属，不改变原记录与照片 ID。
- F2：最多选择 20 条本人记录、安排章节、勾选照片、保存草稿并明确授权提交不可变快照。
- F3：任务领取、最小范围授权、带原因退回、新版重提、版本冲突保护、固定版式 PDF 及失败重试。
- F4：商品/款式/价格/上下架管理、文字/照片定制、本人已完成回忆录版本选择、服务端计价和待支付订单。

管理员不能访问整个私人相册，不能改写原记录，也不能读取退回后尚未重新提交的新草稿。订单保存确认时的价格和定制快照，重复请求不会生成多份订单。

## 升级步骤

保持 MySQL 运行，使用已有项目配置。不要把业务测试套件指向个人资料库。

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.lock.txt
.\.venv\Scripts\python.exe -m flask --app wsgi db upgrade
.\.venv\Scripts\python.exe -m flask --app wsgi db check
.\.venv\Scripts\python.exe run.py
```

迁移终点为 `20261102_workflows`，追加九张业务表，原相册表保持不变。部署时需要具有目标库建表权限的项目连接，无需为了正常升级开放创建其他数据库的权限。历史迁移不能删除。

普通用户在 `/workspace#account` 注册。管理员由维护者交互建立：

```powershell
.\.venv\Scripts\python.exe -m flask --app wsgi create-admin
```

账号密码不预置到仓库。维护者登录后自行上架商品；本机已建立的测试账号和测试商品不会自动出现在其他安装中。

## 验证与限制

本地 SQLite 104 项测试通过，原相册/中英文/新增双角色浏览器流程通过，检查了中文、照片 PDF 预览及 390px 布局。本机 MySQL 连接、追加迁移、`db check` 和网站健康检查通过；完整 MySQL 业务测试使用 GitHub Actions 的专用 `life_album_test` 隔离库。
