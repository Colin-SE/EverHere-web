# 设计报告 F1–F5 范围与实施沿革

更新：2026-11-27。文件名沿用既有链接；当前依据用户提供的五页报告，必做范围为 **F1–F5**。逐项结论见 [功能完成度](feature-completion.md)。

## 原始范围及当前结论

报告首版包括私人相册、回忆录提交、审核和固定版式生产、独立商城、模拟付款/退款/交付。纸质回忆录与独立商品复用订单。O1–O5 后置，真实支付、印刷和物流不是首版必须启用的外部服务。

| 编号 | 当前结论 |
|---|---|
| F1 | 核心已实现。 |
| F2 | 选材、授权、快照及修订已实现。 |
| F3 | 审核/制作核心已实现，审批和生成分两步。 |
| F4 | 核心已实现，实际商品和成品演示数据待准备。 |
| F5 | 部分实现，缺模拟适配器、首次下载限制、逐项取消和业务拒绝审批。 |

## 阶段沿革

- 2026-11-08：用户当时只授权 F1–F4 收敛，未做 F5；旧验证文档只说明该日期状态。
- 共用账号：沿用 members / space_ownerships，新增验证、找回及手机会话。访客认领仍须明确选择。
- P1–P3：相册分页/异常恢复、独立 WebGL 地球、当前人物/记录关联 `/connections`、持久制作任务、图库和订单处理。
- P4：支付宝交易、库存、地址、整单退款、订单授权完整下载和手工物流；生产默认关闭，没有独立报告模拟适配器。
- 2026-11-25：加入 `/v1/sync/*` 和 `/v1/assets/*`，版本历史、回执、冲突及原图校验；修复注册冷却不应阻断找回。
- 2026-11-27：sync 与暖色 UI 合入 main 并部署，品牌图标替换；当前业务基线 `378ddc4`。

旧 `/api/v1/lifegraph/*`、`/api/v1/cloud/*`、`/api/v1/archive/*`、Android JSON/ZIP 交换和 WARM/FOREST 切换已删除，仍不开放。它们与新的 `/connections` 和 `/v1/sync/*` 路径应分别记录。现迁移头为 `20261125_album_sync`。

## 样张及下载

样张最多两页，始终省略至少一页。完整下载现有单独订单路由，核对本人 paid 电子项、修订及退款状态；旧“没有完整下载接口”已不适用于 main。首次完整下载尚不记账，报告对应的取消门槛仍未实现。

## 支付及环境

用户确认支付宝沙箱此前已验证可用。旧本机沙箱文件随用户要求的项目清空删除；本次已重新生成密钥、恢复本机测试环境，并在服务器部署独立 SQLite 沙箱。公网子域名 DNS/证书和控制台参数仍需完成。正式站保持支付宝 disabled。详见 [支付宝配置记录](web-product-p4-alipay.md)。历史可用、当前环境进度和 F5 规则完成度分别记录。
