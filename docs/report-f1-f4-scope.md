# 设计报告 F1—F4 重构范围

更新：2026-11-08。用户明确确认“P1 到 P4”指报告功能编号 **F1—F4**，本次不实施 F5。本文件与当前代码优先于旧 Android 总规划和历史验收记录。参考报告为项目目录中的 `COMP3019J_Design_Report_Template(4)/COMP3019J_Design_Report_Template/main.pdf`，功能定义位于第 2 页。

## 保留与对齐

| 要求 | 当前行为 | 入口 |
|---|---|---|
| F1 私人记录与浏览 | 文字、多图、记录/人物草稿、同 ID 修改、软删除恢复；时间轴、日历、人物与地点读取同一份记录；日/月/年/范围/未知精度；逾期计划不自动完成 | `/` |
| F2 整理和提交回忆录 | 最多 20 条本人记录；主题、章节标题和顺序、选中照片；显式授权；冻结正文、来源 ID/版本和照片字节；退回后新修订保留旧审核版本 | `/workspace#memoirs` |
| F3 审核与制作 | 管理员原子领取；只允许领取人查看授权素材、审核和制作；退回原因、版本检查；固定版式 PDF；失败保留通过材料以便重试；只开放样张 | `/workspace#admin` |
| F4 独立商城 | 奖牌/礼品不依赖回忆录；个人定制文字及授权照片冻结到订单；本人 ready 回忆录可选电子/纸质版；服务端价格与款式版本校验；商品说明、价格、上下架和封面管理 | `/workspace#shop`、`/workspace#orders` |

网站身份统一由 `members` 和 `space_ownerships` 管理，管理员由 `create-admin` 命令建立。保留原签名空间和显式注册认领，保证已有相册资料、照片、草稿和 ID 不因本次源码收缩丢失。登录不自动合并访客资料。中英文显示是已有界面基础能力，继续保留。

地点视图现在包含填写地点名称的记录，不再要求必须有 GPS 坐标；已有合法坐标记录仍可浏览。

## 移除的功能

- 人生脉络的页面、画布、邻域查询、搜索及关系操作 API。
- 共同云账户登录/退出/状态与同步 API、云服务配置项和旧云登录页面。旧 `/login` 地址转到网站账户页。
- Android JSON/ZIP 归档导入导出、暂存预览、恢复确认和归档任务 API。
- WARM/FOREST 外观切换入口、脚本状态和主题覆盖。
- 上述模块专用的服务、浏览器脚本、测试及过时验收报告生成工具。
- 旧宠物/影音/阶段/长期投入节点不再出现在人物 API 中，不能通过人物修改/删除接口处理。

`/api/v1/lifegraph/*`、`/api/v1/cloud/*` 和 `/api/v1/archive/*` 均未注册，直接请求返回 404。旧导航 hash 回退到相册首页。

不提供支付（包括模拟支付）、地址结算、取消/退款、生产发货、物流及完整成品下载。商城订单保持 `unpaid`，接口返回 `paymentAvailable: false`，页面说明当前阶段的边界。

## 样张和已有数据

旧实现给整份 PDF 加 PREVIEW 页脚，仍可读到完整正文。本次使用 `pypdf` 从成品复制最多两页，且始终至少省略一页；两页短稿仅显示封面。样张不携带剩余页面、书签或附件，附有英文样张标记。

制作成功时，成品、样张与 ready 状态在同一事务保存；样张制作失败也视为制作失败。预览接口每次从已保存成品重新生成样张，因此旧库中曾存下的完整预览不会被直接返回。完整文件没有下载路由，通用素材路由只接受当前修订的授权照片。

没有删除数据库行、照片、报告或已执行迁移。停用功能的旧表模型保留为数据库结构兼容，不注册相关业务接口；`record_documents.py` 仅在编辑已有资料时维护其元数据，不提供导入、导出或同步能力。

## 验证方式

所有业务测试使用内存 SQLite 或独立 `_test` 数据库，浏览器使用 5003/5004 的合成 SQLite 服务。运行命令和本轮结果见 [重构验证记录](report-f1-f4-verification.md)。数据库迁移链仍以 `20261102_product_images` 为终点，本次无需新增迁移。
