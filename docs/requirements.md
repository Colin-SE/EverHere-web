本轮另增加语言需求 `WEB-I18N-01`：当前 Web 的简体中文和 English 可由用户选择并在当前浏览器保留，覆盖导航、已有页面、表单、对话框、提示、日期呈现及可访问名称。用户日记、姓名、地点、标签、原图、稳定ID和协议枚举不翻译或改写，语言与中国区/国际区配置独立。

## 采用的技术架构

| 层次 | 约定 | 边界 |
|---|---|---|
| Web 前端 | HTML、CSS、原生 JavaScript | 响应式页面；语言与主题仅为呈现偏好 |
| Web 自有后端 | Python / Flask | Web API、归属校验、草稿、归档、共同云请求代理 |
| Web 自有存储 | MySQL 与照片存储 | 当前安装保存资料；远程部署时资料位于服务器，不宣称浏览器离线保存 |
| Android | 保留 Room / SQLite、SQLCipher、私有照片、DataStore 与 Keystore | 不更换安卓数据库、设置或密钥，不直接读取手机文件 |
| 共同云服务 | 既有 TypeScript / PostgreSQL 与私有照片服务 | 同区域账号、服务端权益、授权数据交换、版本与冲突校验 |

云流程固定为：默认本机保存 → 登录账号不上传人生资料 → 服务端确认有效云同步权益 → 用户明确开启 → 用户选择上传或下载及资料范围 → 预览确认后执行。共同云缺少所需能力时明确不可用，不用本地标志模拟权益或成功同步。

原规划8.3中的 W0/W1/W2 和 IndexedDB 是通用路线参考，不替代本项目已确认的 Flask/MySQL 本机安装架构。浏览器离线、加密缓存和生产部署继续单列为未验收能力。

## 验收口径

- **通过**：该行规定的已有子功能具备代码路径和本轮自动化或浏览器行为证据；仅限注明的环境。
- **部分通过**：已有可运行子集，仍缺该行要求的行为或覆盖。
- **未实现**：没有可供用户完成的产品流程，模型、枚举、协议预留不算实现。
- **待验证**：存在实现或历史证据，但本轮缺少所要求的环境或人工/实机证据。

逐行保留需求编号、验收点、结果、证据、缺口和下一步。子项通过不代表整个4.x模块完整交付；报告中的通过率仅表示已列验收点数量比例，不表示产品整体完成百分比。Android实机、真实共同云、生产、支付和最终用户视觉验收分别记录。
