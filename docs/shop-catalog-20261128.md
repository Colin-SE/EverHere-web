## 导入方法与隔离

商品清单为 `tools/shop-catalog.json`，导入工具为 `tools/seed-shop-catalog.py`。默认预览，传入 `--apply` 才提交。必须显式指定站点、应用目录和预期库名；正式站只允许 `life_album`，服务器沙箱只允许 `life_album_alipay_sandbox`。

```bash
python tools/seed-shop-catalog.py \
  --app-root /home/admin/apps/everhere-web \
  --site production \
  --expected-database life_album \
  --manifest tools/shop-catalog.json \
  --asset-dir app/static/images/shop/catalog-20261128
```

各站独立事务；使用稳定商品/规格编号支持重复执行，已有非清单商品及规格不会被删除。对现有 ¥1 沙箱验收款仅更换封面，不改价格、库存或订单引用。已有库存不由此清单重新初始化。
