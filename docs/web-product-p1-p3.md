# Web P1–P3

范围依据 2026-11-14《Everhere Web 整体产品与异常体验规划》和随后的范围确认。此分支延续中国区共用身份；P4 的资金与履约流程另行实施。

## 相册、账户和异常体验

- `/album` 与 `/records/<id>` 复用现有相册、原记录、草稿和照片归属。首页独立读取相册、最近草稿、回忆录和订单摘要。记录列表使用稳定分页，日期精度保留；日历显示整月已有日期。
- 草稿、记录及照片上传区分传输、服务器校验、草稿保存与正式保存。断网保留当前输入。上传按批次编号重试，保留原图；草稿提交超时后可查询回执。没有浏览器持久离线草稿。
- `/account` 显示邮箱验证状态和安卓设备会话，用户可撤销本人设备。原有邮件验证码、找回和显式认领规则继续适用。已打开页面的写入会校验档案标识，避免换号后将旧输入保存到新档案。

## 地点和人生脉络

- `/places` 提供独立、按需加载的 WebGL 地球，可以拖动、用方向键操作以及主动开启或暂停旋转。仅加载站内静态纹理。模型未接入地图服务、定位、坐标数据或私人足迹层。WebGL、纹理或上下文故障时仍可使用现有地点列表。
- `/connections` 从人物或原记录搜索入口开始，只展开当前空间实际保存且仍有效的关联。每层最多 16 个结果，支持翻页、返回和列表。记录始终通过同一个详情入口查看。地球陆地纹理由 [Natural Earth 1:110m 公共领域陆地数据](https://github.com/nvkelso/natural-earth-vector/blob/v5.1.2/geojson/ne_110m_land.geojson) 生成，仅表现陆地轮廓。

## 回忆录、商城和订单

- `/memoirs`、`/memoirs/<id>` 与 `/admin/memoirs` 提供列表、选材、快照审核、制作和样张。后台生成写入独立持久任务，管理员可看到排队、运行和失败。每个修订复用当前任务，失败保留批准稿。任务进程中断 10 分钟后，重新打开管理队列或该稿件可重新领取。完整 PDF 仍受现有交付范围限制。
- `/shop` 支持搜索及类型筛选、独立详情与定制预览。管理端分开处理商品、封面与补充图库。价格变化时保留当前输入并要求重新确认。下单超时后浏览器可凭原请求编号读取已创建的订单，确认后返回详情。
- `/admin/orders` 提供分页筛选、下单用户、领取和审计。领取人员可核对授权照片、写内部备注或向顾客请求补充；顾客只能读取本人的订单及公开进度。处理完成和终止只改变处理状态，订单支付继续显示待支付，无资金或发货变更。

## 迁移与验证

追加迁移 `20261114_web_workflows` 以 `20261114_shared_identity` 为父版本。已有订单默认处于待处理，原支付字段、商品和定制快照保留。取消数据库升级会丢失新增业务数据，因此迁移不提供自动破坏性降级。升级前应确认近期备份可恢复，使用运行实例的 Flask 配置执行 `flask db upgrade` 后再核对 `flask db check`。

运行 `python -m pytest`。MySQL 并发和恢复库排序规则使用隔离的 `_test` 库。浏览器检查使用 `python tools/workflows-check-server.py` 启动独立 SQLite，在另一个终端运行 `node tools/workflows-browser-check.cjs` 与 `node tools/product-experience-browser-check.cjs`。
